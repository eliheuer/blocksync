# Agent Skills

This directory contains reusable agent guidance for Blocksync font development
and Google Fonts release work. Keep project-specific facts in `AGENTS.md`,
`GF_READINESS.md`, and `documentation/`; keep portable workflow guidance in
`skills/`.

For day-to-day font work, start with:

- `skills/build-font/SKILL.md`
- `skills/font-qa/SKILL.md`
- `skills/edit-glyph/SKILL.md`
- `skills/draw-outline/SKILL.md`
- `skills/compare-reference/SKILL.md`
- `skills/kerning/SKILL.md`
- `skills/proof/SKILL.md`

For Google Fonts onboarding, start with:

- `skills/google-fonts-onboarding/SKILL.md`
- `skills/google-fonts-qa/SKILL.md`
- `skills/google-fonts-coverage-drawing/SKILL.md`
- `skills/google-fonts-packaging/SKILL.md`
- `skills/google-fonts-finalize/SKILL.md`
- `google-fonts-onboarding-checklists.md`
- `google-fonts-official-reference-map.md`

For copying this workflow into another font repo, regenerate and read:

- `../documentation/google-fonts-agent-porting-manifest.md`
