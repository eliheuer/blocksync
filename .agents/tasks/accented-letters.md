# Review accented letters

Start with the designer’s named composites and masters. Inventory the base, mark, anchors and transformed offsets in each master. Freeze every donor and every green glyph. Inspect precomposed and decomposed forms at the same axis settings. Compare the condensed Black and expanded Regular extremes and check an intermediate instance.

Prepare a proof and record correct, fault or designer decision for each named composite. For an assigned placement correction, change only the component offset in a permitted composite and mark the draft purple. Preserve the base, mark and anchors. Use the same scope gate and independent review as the glyph-drafting task. Commit the tested batch with the list of affected composites. Return any required donor or anchor change as a separate design decision.
